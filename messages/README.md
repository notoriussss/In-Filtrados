# messages

Tipos TypeScript de los mensajes WebSocket entre `web` y `gateway`, definidos una sola vez.
Se importan como `import type { ClientMessage } from '@beneath-the-surface/messages'` después de `npm install` en la raíz. Solo exporta tipos, así que no se compila.
Dueño: lo revisan quien hace `web` (D) y quien hace `gateway` (C).
